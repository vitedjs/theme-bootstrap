# Vited Bootstrap Theme

A Bootstrap 6 theme for Vited documentation sites, built with React 19 and
`react-bootstrap-icons-pro` icons.

Features:

- Responsive header and sidebar layout with a mobile navigation drawer
- Light and dark color modes based on Bootstrap's `data-bs-theme`, following
  the system by default and remembering the user's choice
- Localized interface in English and Simplified Chinese
- Locale-aware fuzzy search in a modal dialog, opened with `Ctrl+K` / `⌘K`
- GitHub and Donate links from project metadata
- Markdown and MDX code blocks highlighted with Shiki, with copy controls

Get started with the [installation guide](./installation.md) and see the
[configuration reference](./configuration.md) for all options.
