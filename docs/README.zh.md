# Vited Bootstrap 主题

基于 Bootstrap 6 的 Vited 文档主题，使用 React 19、`react-bootstrap-pro`
组件和 `react-bootstrap-icons-pro` 图标构建。

功能特性：

- 响应式页头和侧边栏布局，移动端使用抽屉式导航
- 基于 Bootstrap `data-bs-theme` 的自动、浅色和深色色彩模式，默认跟随系统并记住用户选择
- 英文和简体中文界面翻译
- 弹窗式本地化模糊搜索，使用 `Ctrl+K` / `⌘K` 打开
- 从项目元数据生成 GitHub 和赞助链接
- 使用 Shiki 高亮 Markdown 和 MDX 代码块，带复制按钮

从[安装指南](./installation.md)开始，并在[配置参考](./configuration.md)中查看所有选项。
